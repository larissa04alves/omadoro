# Id `larissa04alves.omadoro`, permanente

O marketplace do Omarchy trata o id como identificador permanente: um id
listado, aposentado ou renomeado nunca volta a ficar disponível. O repo e o
plugin são da larissa, então o id leva o namespace dela. Uma vez submetido, a
única forma de mudar o nome do plugin é uma listagem nova com id novo, o que
apaga histórico, corações e a pasta de Estado de quem já instalou. Decidimos
fixar o id antes da primeira submissão e não voltar a discuti-lo.
